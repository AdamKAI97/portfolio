# ЛогоПульс — платформа логопеда

Рабочее пространство частного логопеда: от первого сообщения родителя до оплаченного
занятия и поставленного звука. Один экран вместо блокнота, таблицы и переписки.

---

## Что умеет

| Раздел | Зачем он нужен |
|---|---|
| **Пульс дня** | Главный экран: занятия на сегодня с кнопками «провёл / пропуск / отмена», деньги месяца, что требует внимания, задачи-напоминания. |
| **Расписание** | Неделя целиком или один день. Клик по пустой клетке — запись ребёнка, клик по занятию — отметка результата. Предупреждает, если время уже занято. |
| **Журнал занятий** | История всех занятий: тема, что делали, домашнее задание, статус. Прошедшие занятия без отметки выносятся наверх. Выгрузка в CSV. |
| **Ученики** | Картотека детей. В карточке: контакты родителя, заключение, все занятия, звуки и деньги — четыре вкладки. |
| **Воронка приёма** | Канбан: Заявка → Диагностика → Пробное → Занимается → Пауза → Выпустился. Карточки перетаскиваются мышью. Видно, кто застрял без ответа. |
| **Прогресс речи** | Каждый звук проходит этапы: подготовка → постановка → автоматизация → дифференциация → свободная речь. Из отметок собирается отчёт для родителя (можно распечатать или сохранить в PDF). |
| **Финансы** | Баланс каждого ученика, долги, предоплаты, графики по месяцам, чем платят. Вежливое напоминание об оплате копируется одной кнопкой. |
| **Отчёты** | Аналитика с выводами обычными словами: где теряются деньги, сколько пропусков, какой день самый загруженный. |
| **Настройки** | Цены и тарифы, рабочие часы и дни, правило списания за пропуск, резервные копии. |

## Как считаются деньги

Два разных числа, и это принципиально:

- **Начислено** — сумма проведённых занятий. Списывается в момент, когда занятие
  отмечено как проведённое.
- **Получено** — деньги, которые реально пришли (записанные оплаты).
- **Баланс ученика** = получено − начислено. Минус — долг, плюс — оплачено вперёд.

Отменённое заранее занятие не списывается никогда. Пропуск без предупреждения
списывается или нет — переключатель в «Настройках».

## Как запустить

Сборка не нужна — это обычные HTML, CSS и JavaScript.

- **Просто открыть:** двойной клик по `index.html` — работает даже без интернета
  (без сети не подгрузятся шрифты, остальное как обычно).
- **На телефоне:** откройте страницу в браузере и добавьте на главный экран —
  приложение запустится в полный экран.
- **Локальный сервер** (если нужен): `python3 -m http.server 8000`, затем
  `http://localhost:8000/logopulse/`.

## Где хранятся данные

Всё лежит **только в вашем браузере** (localStorage) — ничего не уходит в интернет,
регистрации нет, чужие глаза данные не видят.

Обратная сторона: очистка истории браузера или смена устройства = потеря данных.
Поэтому раз в неделю: **Настройки → Скачать резервную копию**. Это один JSON-файл,
из которого всё восстанавливается кнопкой рядом.

## Устройство проекта

```
logopulse/
├── index.html              каркас приложения
├── manifest.webmanifest    установка на телефон
├── css/
│   ├── base.css            токены темы, типографика, фон
│   ├── layout.css          каркас, меню, шапка
│   ├── components.css      кнопки, панели, формы, окна
│   └── views.css           стили разделов и печати
└── js/
    ├── core.js             утилиты, даты, склонения, формат сумм
    ├── store.js            модель данных, расчёты, демо-кабинет
    ├── ui.js               иконки, окна, уведомления, блоки
    ├── charts.js           графики на чистом SVG
    ├── forms.js            формы ученика, занятия, оплаты
    ├── app.js              навигация, поиск, обучение
    └── views/              девять разделов
```

Зависимостей нет: ни фреймворков, ни сборщика, ни библиотек графиков.
Шрифты — Google Fonts с системным запасным вариантом.

Темы две: тёмная и светлая, переключатель в шапке. При печати всегда светлая.
