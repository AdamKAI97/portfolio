## 1. Что получится в итоге

Бот в Telegram, который:

- записывает доходы и расходы простым сообщением: `45000 такси`, `+3000000 зарплата`, `12k кофе`;
- сам определяет категорию по словам (русские и узбекские слова);
- каждый день напоминает записать траты, а по итогам недели и месяца присылает отчёт;
- считает, **сколько можно потратить сегодня**, чтобы дожить до зарплаты и ещё отложить;
- даёт персональные советы по экономии на основе ваших же цифр;
- ведёт цели, бюджеты по категориям, подписки и долги;
- говорит по-русски и по-узбекски;
- работает **круглосуточно, без вашего компьютера**.

Плюс два сайта:
- **приложение внутри Telegram** (Mini App) — графики, история, цели;
- **админ-панель** в браузере — таблицы, категории, рассылка.

## 2. Как это устроено — в пяти строчках

1. Вы пишете боту сообщение в Telegram.
2. Telegram пересылает его на ваш сайт в облаке (Vercel).
3. Код на сайте разбирает сообщение и пишет операцию в базу (Neon).
4. Бот отвечает вам.
5. Раз в сутки облако само запускает проверку и присылает напоминания и отчёты.

Всё это — три бесплатных сервиса: **Telegram** (бот), **Neon** (база), **Vercel** (сайт и код).

## 3. База данных Neon

База — это «тетрадь», где хранятся все ваши операции. Ваш компьютер тут не участвует.

1. Откройте **https://neon.tech** → **Sign up** → войдите через Google или GitHub.
2. Нажмите **Create project**:
   - **Project name:** `finance-bot`
   - **Postgres version:** оставьте как есть
   - **Region:** выберите ближайший (например, Europe Frankfurt)
3. Нажмите **Create**.
4. Откроется окно **Connection string**. В списке выберите **Prisma** или **Node.js** и нажмите значок копирования.

Строка выглядит так — сохраните её в заметки, она понадобится дальше:

```
postgresql://neondb_owner:ПАРОЛЬ@ep-имя-проекта-123456.eu-central-2.aws.neon.tech/neondb?sslmode=require
```

> **Потеряли строку?** Neon → ваш проект → **Dashboard** → **Connection string** → **Show password**.

> **Важно:** ничего в этой строке править не надо. Даже если в конце есть `&channel_binding=require` —
> проект сам уберёт лишнее.

## 4. Бот в Telegram через BotFather

1. В Telegram найдите **@BotFather** (у настоящего есть синяя галочка) и нажмите **Start**.
2. Отправьте команду:
   ```
   /newbot
   ```
3. BotFather спросит **имя бота** — это подпись в чатах, любая:
   ```
   Мои финансы
   ```
4. Затем спросит **username** — он должен быть уникальным и **обязательно заканчиваться на `bot`**:
   ```
   moi_finansy_2026_bot
   ```
   Если имя занято — просто придумайте другое, BotFather скажет об этом.
5. В ответ придёт сообщение с токеном:
   ```
   1234567890:AAExampleTokenFromBotFather-xxxxxxxxxxx
   ```
   **Это пароль от вашего бота.** Сохраните его в заметки и никому не показывайте.

Полезно сразу сделать бота приятнее (необязательно):
- `/setdescription` — текст, который видит новый пользователь;
- `/setabouttext` — короткое описание в профиле;
- `/setuserpic` — аватар.

> **Кнопку приложения в BotFather настраивать НЕ нужно** — бот поставит её сам.

## 6. Размещение в облаке Vercel

Vercel — это бесплатный «дом» для кода. Он берёт код с GitHub и делает из него работающий сайт.

### 6.1. Регистрация

1. Откройте **https://vercel.com**
2. **Sign Up** → **Continue with GitHub** → **Authorize Vercel**
3. Если спросят про план — выберите **Hobby** (бесплатный)

Карта не нужна.

### 6.2. Импорт проекта

1. Нажмите **Add New…** → **Project**
2. Найдите репозиторий **portfolio** → **Import**
   - Нет в списке? Нажмите **Adjust GitHub App Permissions** и разрешите доступ к нему.

Откроется страница настройки. Здесь **важный подводный камень**:

> ### ⚠️ Грабли №1: в выборе папки нет `finbot`
>
> Если нажать **Edit** у поля **Root Directory**, откроется список папок — и `finbot` там не будет,
> только `portfolio`. Это **не ошибка**: Vercel показывает папки главной ветки репозитория,
> а наш проект лежит в другой ветке.
>
> **Что делать:** нажмите **Cancel**, оставьте Root Directory как есть (`/`).
> Папку укажем вручную через две минуты — там это обычное текстовое поле.

3. **Framework Preset** — оставьте **Other**.

### 6.3. Переменные (три штуки)

На той же странице раскройте блок **Environment Variables** и добавьте три записи.
Для каждой: имя в поле **Key**, значение в поле **Value**, кнопка **Add**.

| Key | Value | Откуда взять |
|---|---|---|
| `DATABASE_URL` | `postgresql://neondb_owner:...` | часть 3 (Neon) |
| `BOT_TOKEN` | `1234567890:AAE...` | часть 4 (BotFather) |
| `ADMIN_TOKEN` | придумайте пароль, например `moi-parol-2026` | это пароль от админ-панели |

Проверьте глазами: в значениях **не должно быть пробелов** в начале и в конце.

4. Нажмите **Deploy** и подождите 2–4 минуты.

> ### ⚠️ Грабли №2: первая сборка показывает «не тот» сайт
>
> После первой сборки по адресу проекта откроется старый сайт из корня репозитория,
> а не финансовое приложение. Это **нормально** — мы ещё не сказали Vercel про папку `finbot`.
> Сейчас скажем.

### 6.4. Папка проекта

> ### ⚠️ Грабли №3: Root Directory лежит не там, где ожидаешь
>
> В новом интерфейсе Vercel это поле **не** в разделе General, а в **Build and Deployment**.
> И его легко спутать с полем **Project Name** — это разные вещи: Project Name просто
> переименовывает проект и ни на что не влияет.

1. В проекте откройте **Settings** (вверху)
2. В меню слева выберите **Build and Deployment**
   *(в старом интерфейсе — раздел **General**)*
3. Пролистайте до блока **Root Directory**
4. Впишите руками:
   ```
   finbot
   ```
5. Нажмите **Save** рядом с этим блоком

### 6.5. Рабочая ветка

> ### ⚠️ Грабли №4: Production Branch тоже переезжает
>
> В разных версиях интерфейса это поле в разных местах. Проверьте по порядку.

**Вариант А:** **Settings** → **Git** → блок **Production Branch**.
Он в **верхней** части страницы — выше блоков «Git LFS» и «Deploy Hooks».
Если видите только их — прокрутите страницу вверх.

**Вариант Б:** **Settings** → **Environments** → **Production** → блок **Branch Tracking**.

В найденное поле впишите и сохраните:

```
claude/speech-therapy-practice-platform-gnqgnc
```

### 6.6. Пересборка

1. Вкладка **Deployments** (вверху)
2. У самой верхней записи нажмите **⋯** → **Redeploy** → ещё раз **Redeploy**
3. Подождите 2–4 минуты

**Как понять, что получилось:** откройте адрес проекта (вкладка **Project**, адрес вида
`https://portfolio-xxxx.vercel.app`). Должно открыться финансовое приложение, а не старый сайт.

Если в деталях сборки видно **Source: claude/speech-therapy-practice-platform-gnqgnc** —
ветка подхвачена правильно.

## 7. Подключение бота и проверка

### 7.1. Одна ссылка

Соберите адрес из своего домена и своего `ADMIN_TOKEN`:

```
https://ВАШ-АДРЕС.vercel.app/api/setup?token=ВАШ_ADMIN_TOKEN
```

Пример: домен `portfolio-beryl-eight-69.vercel.app`, пароль `moi-parol-2026` →

```
https://portfolio-beryl-eight-69.vercel.app/api/setup?token=moi-parol-2026
```

Откройте её в браузере. Должна появиться страница **«✅ Бот подключён»** с именем вашего бота.

Эта ссылка делает три вещи: говорит Telegram, куда присылать сообщения; ставит боту список
команд; ставит кнопку приложения в чате.

### 7.2. Проверка в Telegram

1. Найдите своего бота по username и нажмите **Start**
2. Выберите язык
3. Напишите:
   ```
   45000 такси
   ```
   Бот ответит «✅ Записал» и сам поставит категорию «Транспорт».
4. Попробуйте ещё:
   - `+3000000 зарплата` — доход
   - `12k кофе` — расход 12 000
   - кнопка **📊 Отчёт** — сводка за месяц
   - кнопка **💡 Совет** — персональные советы
5. Слева от поля ввода появится кнопка **Финансы** — это приложение с графиками.

**Главная проверка:** выключите компьютер и напишите боту снова. Ответил — всё работает.

### 7.3. Админ-панель

```
https://ВАШ-АДРЕС.vercel.app/admin
```

Пароль — ваш `ADMIN_TOKEN`.

## 8. Страница диагностики — главный инструмент

Если что-то не работает, **не гадайте**. Откройте:

```
https://ВАШ-АДРЕС.vercel.app/api/status?token=ВАШ_ADMIN_TOKEN
```

Страница проверяет всё по пунктам и под каждой проблемой пишет, что делать:

| Строка | Что означает |
|---|---|
| Переменная DATABASE_URL / BOT_TOKEN / ADMIN_TOKEN | заданы ли три значения в Vercel |
| База данных | отвечает ли Neon, сколько пользователей и операций |
| Сайт доступен извне | не закрыт ли сайт защитой Vercel (иначе Telegram не дойдёт) |
| Токен бота | принимает ли его Telegram, и как зовут бота |
| **Адрес приёма сообщений** | самая важная строка: сервер сам стучится в свой адрес приёма |
| Подключение Telegram | прописан ли вебхук и на тот ли адрес |
| Необработанные сообщения | сколько сообщений застряло в очереди |
| Последняя ошибка доставки | что именно ответил сайт Telegram в последний раз |

Внизу страницы кнопка **«Подключить бота заново»** — она заново прописывает адрес
и очищает застрявшие сообщения. В большинстве случаев одного нажатия достаточно.

> **Как читать страницу:** если «Адрес приёма сообщений» **зелёный**, а «Последняя ошибка
> доставки» красная — ошибка уже в прошлом, просто нажмите «Подключить бота заново».
> Если «Адрес приёма сообщений» **красный** — проблема прямо сейчас, смотрите подсказку под таблицей.

Если понадобятся подробности — **Vercel → Logs**: там видно каждый запрос от Telegram
и текст ошибки, если код падает.

## 9. Все ошибки, которые встретились, и их лечение

Это реальный список грабель с первого запуска. Если что-то пойдёт не так — ищите здесь.

### При настройке Vercel

| Что видите | Почему | Что делать |
|---|---|---|
| В выборе Root Directory нет папки `finbot` | Vercel показывает папки главной ветки, а проект в другой ветке | Нажать **Cancel** и вписать `finbot` вручную: Settings → Build and Deployment |
| Не нахожу поле **Root Directory** | В новом интерфейсе оно переехало | **Settings → Build and Deployment**, а не General |
| Вписал `finbot` в **Project Name** | Это другое поле — просто имя проекта | Безвредно. Нужное поле — Root Directory (см. выше) |
| Не нахожу **Production Branch** | Поле в разных версиях в разных местах | **Settings → Git** (вверху страницы) либо **Settings → Environments → Production → Branch Tracking** |
| Открывается старый сайт, а не приложение | Root Directory ещё `/` | Вписать `finbot`, затем **Deployments → ⋯ → Redeploy** |
| `404: NOT_FOUND` на всём сайте | Не задана папка или ветка | Проверить Root Directory и Production Branch, сделать Redeploy |
| Сборка упала — красный **Error** | Обычно опечатка в переменных | **Deployments** → нажать на сборку → **Build Logs**, прочитать последние строки |

### При подключении бота

| Что видите | Почему | Что делать |
|---|---|---|
| `/api/setup` пишет «Неверный пароль» | `token` в ссылке не совпадает с `ADMIN_TOKEN` в Vercel | Сверить символ в символ; проверить пробелы в значении переменной |
| **Бот молчит**, в диагностике «Последняя ошибка доставки: 404 Not Found» | Telegram стучался, когда сайт ещё отдавал старый сайт | Нажать «Подключить бота заново» — очистит очередь |
| Бот молчит, «Адрес приёма сообщений: ошибка 404» **прямо сейчас** | Хостинг не доводил до кода вложенные адреса. В проекте это уже исправлено правилом в `vercel.json` | Убедиться, что стоит свежая версия кода (Deployments → верхняя сборка), и сделать Redeploy |
| «Необработанные сообщения: 3» | Сообщения застряли, пока была ошибка | «Подключить бота заново» |
| «Сайт доступен извне: нет» | Включена защита Vercel — Telegram получает отказ | **Settings → Deployment Protection** → выключить защиту для Production |
| «Токен бота: не рабочий» | Токен скопирован не полностью или отозван | Взять новый: BotFather → `/mybots` → бот → **API Token** |
| Ошибка про базу данных | Неверная строка или проект Neon спит | Проверить `DATABASE_URL`; открыть neon.tech, чтобы проект проснулся |

### При работе бота и приложения

| Что видите | Почему | Что делать |
|---|---|---|
| Приложение в обычном браузере показывает ошибку | Так и должно быть, если сайт не открыт внутри Telegram: приложению нужна подпись Telegram | Открывать кнопкой **Финансы** в чате с ботом |
| Кнопки **Финансы** нет в чате | Telegram кеширует кнопку меню | Закрыть и снова открыть чат с ботом; если не помогло — открыть `/api/setup?token=…` |
| Бот не спрашивает категорию | Он угадал её по словам — это задумано | Напишите только число (`100000`) — тогда предложит выбрать |
| «Не вижу категории» в приложении | Отдельной страницы категорий нет | Нажмите **+** внизу — категории на экране добавления операции; ещё они видны в **Отчётах** |
| В приложении пусто после простоя | База «просыпается» | Подождать 10–20 секунд и обновить |
| Бот отвечает с задержкой в первый раз | Облако и база «просыпаются» после простоя | Нормально, дальше быстро |

### При запуске на своём компьютере

| Что видите | Почему | Что делать |
|---|---|---|
| Окно моргнуло и закрылось | Архив не распакован, файлы запускаются «внутри архива» | Правой кнопкой по ZIP → **Извлечь всё** |
| `node` не распознан | Node.js не установлен или компьютер не перезагружен | Установить с nodejs.org (кнопка **LTS**) и перезагрузиться |
| `npm.ps1 … выполнение сценариев отключено` | Политика PowerShell | Запускать через файл `.bat`, а не из PowerShell |
| «Система Windows защитила ваш компьютер» | Файл скачан из интернета | **Подробнее** → **Выполнить в любом случае** |
| macOS: «неизвестный разработчик» | То же самое | Правой кнопкой по файлу → **Открыть** → **Открыть** |
| Не получается открыть терминал в папке | Перетаскивание папки — неочевидный приём | Использовать файлы `1-НАСТРОЙКА` и `2-ЗАПУСК` двойным щелчком |
| **Бот замолчал после локального запуска** | Локальный бот при старте отключает облачный вебхук и забирает сообщения себе. Когда окно закрыли — бот замолчал совсем | Открыть `/api/setup?token=…` — вернёт бота в облако. **Одновременно держать оба режима нельзя** |

## 10. Запуск на своём компьютере (необязательно)

Нужен, только если хотите что-то проверить или поменять своими руками.
Для обычного пользования достаточно облака.

1. Установите **Node.js** с https://nodejs.org (зелёная кнопка **LTS**), затем **перезагрузите компьютер**.
2. Скачайте проект: откройте
   `https://github.com/AdamKAI97/portfolio/tree/claude/speech-therapy-practice-platform-gnqgnc`
   → **Code** → **Download ZIP** → **распакуйте** архив (правой кнопкой → «Извлечь всё»).
3. Зайдите в папку `finbot`.
4. Двойной щелчок по **`1-НАСТРОЙКА-Windows.bat`** (на Mac — правой кнопкой по
   `1-НАСТРОЙКА-Mac.command` → **Открыть**). Скрипт спросит три значения — те же, что в части 6.3.
5. Двойной щелчок по **`2-ЗАПУСК-Windows.bat`**. Появятся адреса:
   - приложение — http://localhost:5173
   - админка — http://localhost:5174
6. Закрыли окно — локальный бот выключился.

**Важное правило:** пока открыто окно локального запуска, бот работает с вашего компьютера,
а не из облака. Закончили — откройте `/api/setup?token=…`, чтобы вернуть бота в облако.

Обновить локальную копию: двойной щелчок по **`3-ОБНОВИТЬ-Windows.bat`** — скачает свежие
файлы и сохранит ваши настройки.

## 11. Напоминания и расписание

Работает само: ежедневное напоминание (если за день ничего не записано), итоги недели
в воскресенье, итоги месяца 1-го числа, предупреждение при 80% и 100% бюджета категории,
напоминание о регулярных платежах.

На бесплатном тарифе Vercel проверка запускается **раз в сутки в 21:00 по Ташкенту**.

**Поменять время:** в файле `finbot/vercel.json` строка

```json
"schedule": "0 16 * * *"
```

`16` — час по Гринвичу. Ташкент = Гринвич + 5:

| Нужно в Ташкенте | Написать |
|---|---|
| 19:00 | `0 14 * * *` |
| 21:00 | `0 16 * * *` |
| 22:00 | `0 17 * * *` |

После изменения файла Vercel пересоберёт проект сам.

**Нужна точность до минуты?** Зарегистрируйтесь на бесплатном **https://cron-job.org**
и создайте задание, которое каждые 15 минут открывает адрес:

```
https://ВАШ-АДРЕС.vercel.app/api/cron?token=ВАШ_ADMIN_TOKEN
```

## 12. Безопасность: смена ключей

Если токен бота или пароль базы где-то «засветились» (в переписке, на скриншоте) — меняйте.

1. **Токен бота:** @BotFather → `/mybots` → ваш бот → **API Token** → **Revoke current token**
2. **Пароль базы:** Neon → проект → **Dashboard** → **Reset password**
3. В Vercel: **Settings → Environment Variables** → обновите `BOT_TOKEN` и `DATABASE_URL`
4. **Deployments → ⋯ → Redeploy**
5. Откройте `/api/setup?token=…` ещё раз

Ещё правила:
- пароль `ADMIN_TOKEN` — не короткий и не `123`: он открывает админ-панель со всеми операциями;
- файл `backend/.env` на компьютере никому не пересылайте — там оба ключа;
- в GitHub ключи не попадают: файл `.env` исключён из репозитория.

## 13. Как обновлять и как сделать второго бота

**Обновления кода.** Vercel подхватывает изменения сам — через минуту после того,
как код на GitHub обновился. Нажимать ничего не нужно.

**Второй бот** (например, для родственника):
1. Новый бот у @BotFather → новый токен.
2. Новый проект в Neon → новая строка подключения (можно и ту же базу, но тогда данные общие).
3. В Vercel: **Add New… → Project** → тот же репозиторий → **Import**.
   Дальше те же шаги 6.3–6.6, но с новыми значениями переменных.
4. Открыть `/api/setup?token=…` на новом адресе.

Один проект Vercel = один бот. Два бота в одном проекте работать не будут.
