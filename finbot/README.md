# 💰 Финансовый бот — Telegram Mini App + Админ-панель

Личный помощник по учёту денег: записывает доходы и расходы, каждый день напоминает
внести траты, показывает аналитику и даёт персональные советы, как сэкономить и накопить.
Интерфейс на **русском и узбекском** языках.

Проект состоит из трёх частей и целиком работает на вашем компьютере (localhost):

| Часть | Папка | Что это |
|---|---|---|
| Backend + бот | `backend/` | Node.js, Telegraf, Express API, Prisma, планировщик напоминаний |
| Mini App | `miniapp/` | React-приложение внутри Telegram (для вас) |
| Админ-панель | `admin/` | React-панель в браузере: таблицы операций, категории, пользователи |


---

## ☁️ Круглосуточная работа (рекомендуется)

Бот, приложение и админка размещаются бесплатно на Vercel — после этого компьютер не нужен:
бот отвечает и присылает напоминания сам. Пошагово: **[DEPLOY.md](./DEPLOY.md)**.

Архитектура в облаке: Telegram шлёт обновления на вебхук, один обработчик обслуживает бота,
API и напоминания, фронтенды собираются в статику и раздаются с того же домена,
поэтому Mini App работает без отдельных настроек и туннелей.

## 💻 Быстрый старт на своём компьютере — две команды

```bash
cd finbot

node setup.mjs     # спросит строку Neon и токен бота, всё установит и создаст таблицы
node dev.mjs       # запустит бота, Mini App и админ-панель в одном окне
```

`setup.mjs` делает всё сам: создаёт `backend/.env`, ставит зависимости во всех трёх папках,
создаёт таблицы в базе, записывает стартовые категории и проверяет токен бота.
Данные можно передать и сразу:

```bash
node setup.mjs --db "postgresql://..." --token "123456:AA..."
```

`dev.mjs` поднимает все три части сразу и **сам следит за ngrok**: как только вы в другом окне
выполните `ngrok http 5173`, скрипт подхватит https-адрес, пропишет его в `.env` и перезапустит бота —
останется только один раз вставить этот адрес в BotFather. Остановить всё — `Ctrl+C`.

Ниже — та же настройка вручную, по шагам, если хотите понимать каждый этап.

## 📋 Что нужно подготовить (15 минут)

### Шаг 1. База данных PostgreSQL на Neon (бесплатно)

1. Откройте **https://neon.tech** → **Sign up** (войдите через Google или GitHub).
2. Нажмите **Create project**.
   - Project name: `finance-bot`
   - Postgres version: оставьте по умолчанию
   - Region: выберите ближайший (например, Europe Frankfurt)
3. После создания откроется окно **Connection string**. Выберите в списке **Prisma** или **Node.js**
   и нажмите иконку копирования.
4. Строка выглядит так:
   ```
   postgresql://neondb_owner:AbCdEf123@ep-cool-name-123456.eu-central-1.aws.neon.tech/neondb?sslmode=require
   ```
   Сохраните её — это ваш `DATABASE_URL`.

> Если строку потеряли: Neon → ваш проект → **Dashboard** → **Connection string** → **Show password**.

### Шаг 2. Бот в Telegram через BotFather

1. Откройте Telegram и найдите **@BotFather** (у него синяя галочка).
2. Нажмите **Start** (или отправьте `/start`).
3. Отправьте команду:
   ```
   /newbot
   ```
4. BotFather спросит **имя бота** (как будет подписан в чатах). Напишите, например:
   ```
   Мои финансы
   ```
5. Затем спросит **username** — он должен быть уникальным и **обязательно заканчиваться на `bot`**:
   ```
   my_finance_2026_bot
   ```
6. В ответ придёт сообщение `Done! Congratulations on your new bot.` и строка вида:
   ```
   123456789:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw
   ```
   Это ваш **BOT_TOKEN**. Никому его не показывайте.

Полезные команды BotFather (пригодятся позже):
- `/mybots` → выбрать бота → **Edit Bot** → поменять имя, описание, картинку;
- `/setdescription` — текст, который видят новые пользователи;
- `/setuserpic` — аватар бота.

## 🔑 Настройка .env

Создайте файл `.env` из шаблона:

```bash
cd finbot/backend
cp .env.example .env        # Windows PowerShell: copy .env.example .env
```

Откройте `.env` любым редактором и подставьте свои данные:

```env
DATABASE_URL="сюда строку из Neon"
BOT_TOKEN="сюда токен из BotFather"

WEBAPP_URL="http://localhost:5173"
PORT=4000

ADMIN_TOKEN="придумайте пароль для админ-панели"

DEFAULT_LANGUAGE="ru"
DEFAULT_CURRENCY="UZS"
DEFAULT_TIMEZONE="Asia/Tashkent"

ALLOW_DEV_AUTH="true"
DEV_TELEGRAM_ID=""
```

> `ALLOW_DEV_AUTH="true"` нужен, чтобы Mini App открывалась в обычном браузере для проверки.
> Когда всё настроите и будете пользоваться только через Telegram — поставьте `"false"`.

## 🗄 Миграции базы и стартовые данные

```bash
cd finbot/backend

# создать таблицы в базе Neon
npm run db:push

# записать базовые категории (еда, транспорт, жильё, зарплата и т.д.)
npm run db:seed
```

Должно появиться:
```
🚀  Your database is now in sync with your Prisma schema.
✅ Готово: 10 категорий расходов, 5 категорий доходов.
```

Полезно:
- `npm run db:studio` — открыть визуальный просмотр базы в браузере;
- `npm run db:migrate` — то же самое, но с файлами миграций (для истории изменений схемы);
- `npm run db:reset` — стереть базу и создать заново (все данные удалятся).

## 🌐 ngrok: как открыть Mini App внутри Telegram

Telegram пускает в Mini App только адреса с **https**, а `localhost` он не видит.
`ngrok` создаёт временный https-адрес, ведущий на ваш компьютер.

**Важно:** нужен только **один** туннель — на порт `5173`.
Mini App обращается к API через `/api`, а Vite сам перенаправляет эти запросы на `localhost:4000`.

### Шаг 1. Установить ngrok
1. Зарегистрируйтесь на **https://ngrok.com** (бесплатно).
2. Скачайте ngrok для своей системы и распакуйте.
3. В личном кабинете ngrok откройте **Your Authtoken**, скопируйте его и выполните:
   ```bash
   ngrok config add-authtoken ВАШ_ТОКЕН
   ```

> Если проект запущен через `node dev.mjs`, шаги 2–3 делать не нужно — адрес подхватится сам,
> достаточно выполнить `ngrok http 5173` и вставить показанный адрес в BotFather.

### Шаг 2. Запустить туннель (четвёртый терминал)
```bash
ngrok http 5173
```
В окне появится строка:
```
Forwarding   https://abcd-12-34-56-78.ngrok-free.app -> http://localhost:5173
```
Скопируйте адрес `https://...ngrok-free.app`.

### Шаг 3. Подставить адрес в бэкенд
В файле `finbot/backend/.env` замените:
```env
WEBAPP_URL="https://abcd-12-34-56-78.ngrok-free.app"
```
Перезапустите терминал 1 (`Ctrl+C`, затем `npm run dev`).

### Шаг 4. Привязать Mini App к боту в BotFather
1. Откройте **@BotFather** → `/mybots` → выберите своего бота.
2. **Bot Settings** → **Menu Button** → **Configure menu button**.
3. Вставьте адрес из ngrok и отправьте.
4. Введите название кнопки, например: `Финансы`.

Готово. Откройте бота: внизу появится кнопка меню, а в клавиатуре — «📱 Приложение».

> Бесплатный ngrok **меняет адрес при каждом перезапуске**.
> После перезапуска нужно снова: обновить `WEBAPP_URL`, перезапустить бэкенд и обновить ссылку в BotFather.

## 🤖 Как пользоваться ботом

**Самый быстрый способ — просто написать боту сообщение:**

| Сообщение | Что произойдёт |
|---|---|
| `45000 такси` | расход 45 000, категория «Транспорт» определится сама |
| `+3000000 зарплата` | доход 3 000 000, категория «Зарплата» |
| `12k кофе` | расход 12 000 |
| `2,5 млн аренда` | расход 2 500 000, категория «Жильё» |
| `50 ming taksi` | работает и по-узбекски |

Кнопки меню: `➖ Расход` · `➕ Доход` · `📊 Отчёт` · `🎯 Цели` · `💡 Совет` · `🏆 Достижения` · `📱 Приложение` · `⚙️ Настройки`

Команды: `/start` `/add` `/income` `/report` `/goals` `/advice` `/debts` `/achievements` `/settings` `/language` `/export`

## ✨ Возможности

**Учёт**
- быстрый ввод текстом с автоопределением категории (русский и узбекский словари);
- 15 категорий из коробки, свои можно добавить;
- кнопка «↩️ Удалить запись» сразу после сохранения;
- экспорт всех операций в CSV (открывается в Excel).

**Напоминания (планировщик работает по часовому поясу пользователя)**
- ежедневно в выбранное время — если за день ничего не записано;
- воскресенье 20:00 — итоги недели;
- 1-е число 10:00 — итоги прошлого месяца;
- предупреждение при 80% и 100% использования бюджета категории;
- напоминание о регулярных платежах (подписки, аренда).

**Аналитика**
- отчёт за 7 дней / текущий месяц / прошлый месяц;
- разбивка по категориям с процентами;
- прогноз расходов до конца месяца;
- сравнение с прошлым месяцем;
- средний расход в день, дни без трат;
- график доходов и расходов за 6 месяцев (в Mini App).

**Советы по экономии (считаются по вашим данным)**
- главная статья расходов и сколько даст её сокращение на 20% за год;
- «эффект мелких трат» — сумма покупок до 50 000 в год;
- правило 50/30/20 для вашего бюджета;
- «сначала заплати себе» — сколько откладывать в день зарплаты;
- подушка безопасности: на сколько месяцев хватит накоплений;
- прогноз «уйдёте в минус» до конца месяца;
- выходные против будней;
- стратегия погашения долгов «снежным комом».

**Мотивация**
- 🔥 серия дней учёта и рекорд;
- 🏆 10 достижений (первая запись, 7 и 30 дней подряд, дни без трат, закрытая цель, подушка и др.);
- ❤️‍🔥 индекс финансового здоровья 0–100 по 5 факторам;
- 🪙 округление сдачи: разница до 1000 сум автоматически уходит в первую цель;
- 🎉 отметка «день без трат».

**Цели, бюджеты, долги**
- цели с прогрессом и прогнозом даты достижения;
- месячные лимиты по категориям;
- учёт долгов «я должен» / «мне должны».

**Mini App**
- «Можно потратить сегодня» — дневной лимит с учётом плана дохода, нормы сбережений
  и предстоящих регулярных платежей; при перерасходе показывает минус;
- светлая и тёмная тема (следует теме Telegram, переключается вручную);
- редактирование и удаление операции в один тап по строке;
- быстрые кнопки часто повторяющихся сумм;
- подписки и регулярные платежи: список, пауза, сумма в месяц;
- долги «я должен» / «мне должны» прямо в приложении;
- история сгруппирована по дням с итогом каждого дня;
- онбординг из 3 слайдов с выбором языка (показывается один раз);
- «истории» сверху — персональные инсайты в формате Stories;
- главный экран с балансом месяца и быстрым добавлением;
- статистика: плитки, рейтинг категорий, график за 6 месяцев, история с фильтрами;
- повтор операции в один тап из истории;
- профиль: достижения, язык, время напоминания, норма сбережений, экспорт.

**Админ-панель**
- обзор: пользователи, операции, доходы/расходы, график за 6 месяцев, топ категорий;
- таблица всех операций с фильтрами (месяц, тип, пользователь) и удалением;
- CRUD категорий: название RU/UZ, эмодзи, цвет, ключевые слова для автокатегории;
- пользователи: язык, напоминания, детали, цели, последние операции;
- рассылка сообщения всем пользователям;
- выгрузка CSV.

## ❓ Частые проблемы

| Проблема | Решение |
|---|---|
| `❌ В файле .env не заполнено: DATABASE_URL, BOT_TOKEN` | Заполните `.env` в папке `backend` |
| `Can't reach database server` | Проверьте, что в `DATABASE_URL` есть `?sslmode=require`, и что проект Neon активен |
| `401 Unauthorized` в Mini App | Поставьте `ALLOW_DEV_AUTH="true"` в `.env` и перезапустите бэкенд |
| Кнопка «📱 Приложение» открывает просто ссылку | Значит `WEBAPP_URL` начинается с `http://`. Telegram принимает только `https` — используйте ngrok |
| В Mini App пустой экран через ngrok | Проверьте, что запущен `npm run dev` в `miniapp` и туннель идёт на порт `5173` |
| Бот не отвечает | Убедитесь, что терминал 1 запущен и в нём написано `🤖 Бот @… запущен` |
| Ошибка `409 Conflict` у бота | Бот уже запущен в другом терминале — закройте лишний |
| Напоминание не приходит | Проверьте `⚙️ Настройки` → напоминания включены, и часовой пояс `DEFAULT_TIMEZONE` |

## 🔒 Безопасность

- `.env` не попадает в git (добавлен в `.gitignore`) — токен бота и пароль базы останутся у вас.
- Mini App проверяет подпись Telegram (HMAC-SHA256) — чужой не сможет открыть ваши данные.
- Админ-панель закрыта токеном `ADMIN_TOKEN`.
- Перед реальным использованием поставьте `ALLOW_DEV_AUTH="false"` и смените `ADMIN_TOKEN`.
