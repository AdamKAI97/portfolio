# 🚀 Пошаговый запуск — для тех, кто не программист

Инструкция рассчитана на то, что вы никогда не работали с терминалом.
Делайте строго по шагам сверху вниз. Всего нужно около 20 минут.

---

## Шаг 0. Установите Node.js (один раз)

Node.js — это программа, которая умеет запускать наш проект.

1. Откройте **https://nodejs.org**
2. Нажмите большую зелёную кнопку с надписью **LTS** (это стабильная версия).
3. Запустите скачанный файл и нажимайте **Далее → Далее → Установить**, ничего не меняя.
4. **Перезагрузите компьютер** (или хотя бы закройте все окна терминала) — иначе система
   не увидит новую программу.

### Как открыть терминал

- **Windows:** нажмите клавишу `Win`, наберите `powershell`, нажмите Enter.
- **macOS:** нажмите `Cmd + Пробел`, наберите `терминал`, нажмите Enter.

Откроется чёрное (или белое) окно, куда можно печатать команды.

### Проверьте, что Node.js установился

Напечатайте в терминале и нажмите Enter:

```
node -v
```

**Должно появиться:** `v20.11.0` или другое число, начинающееся с `v18`, `v20`, `v22`.
Если написано «не является внутренней или внешней командой» — Node.js не установился
или вы не перезапустили терминал. Вернитесь к пункту 1.

## Шаг 2. Откройте терминал внутри папки `finbot`

Это самый неочевидный момент, поэтому подробно:

1. Откройте терминал (как в Шаге 0).
2. Напечатайте `cd` и **пробел** — но Enter пока не нажимайте:
   ```
   cd 
   ```
3. Мышкой **перетащите папку `finbot`** прямо в окно терминала.
   Путь подставится сам, получится что-то вроде:
   ```
   cd C:\Users\Asror\Desktop\portfolio\finbot
   ```
4. Теперь нажмите Enter.

### Проверьте, что вы в нужной папке

Напечатайте:

```
dir
```
(на macOS — `ls`)

**Должны увидеть** в списке: `admin`, `backend`, `miniapp`, `setup.mjs`, `dev.mjs`, `README.md`.
Если этих названий нет — вы не в той папке, повторите пункты 2–4.

## Шаг 3. Настройка проекта

Напечатайте:

```
node setup.mjs
```

Скрипт задаст три вопроса — отвечайте по очереди:

1. **`Строка подключения Neon (DATABASE_URL):`**
   Вставьте строку из личного кабинета Neon (вида `postgresql://neondb_owner:...`) и нажмите Enter.
2. **`Токен бота из BotFather (BOT_TOKEN):`**
   Вставьте токен (вида `1234567890:AAE...`) и нажмите Enter.
3. **`Пароль для админ-панели [finbot-admin]:`**
   Придумайте любой пароль или просто нажмите Enter, чтобы оставить предложенный.
   **Запомните его** — он понадобится в Шаге 7.

> Как вставить текст: в PowerShell и в Терминале macOS работает правая кнопка мыши,
> а также `Ctrl+V` / `Cmd+V`.

После ответов команда будет работать **3–5 минут** и много чего напишет — это нормально.

**Что должно появиться в конце:**

```
> Создаю таблицы в базе Neon
  OK Таблицы созданы

> Записываю стартовые категории
✅ Готово: 10 категорий расходов, 5 категорий доходов.

> Проверяю токен бота
  OK Бот найден: @ваш_бот (Мои финансы)

Настройка завершена.
```

**Запишите имя бота** (`@ваш_бот`) — оно понадобится в Шаге 5.

Эту настройку достаточно выполнить **один раз**. Повторно она нужна, только если вы
поменяете токен бота или пароль базы.

## Шаг 5. Проверьте бота в Telegram

1. Откройте Telegram, в поиске наберите имя вашего бота (`@ваш_бот` из Шага 3).
2. Нажмите **Start**.
3. Бот предложит выбрать язык — нажмите 🇷🇺 Русский или 🇺🇿 O'zbekcha.
4. Напишите боту обычное сообщение:
   ```
   45000 такси
   ```
   Бот ответит «✅ Записал» и сам определит категорию «Транспорт».
5. Попробуйте ещё:
   - `+3000000 зарплата` — это доход
   - `12k кофе` — расход 12 000
   - нажмите кнопку **📊 Отчёт** — увидите сводку за месяц
   - нажмите **💡 Совет** — получите персональные советы по экономии

### Приложение можно посмотреть прямо в браузере

Откройте **http://localhost:5173** — увидите то же приложение, что будет внутри Telegram.
Это удобно, чтобы посмотреть дизайн, не настраивая ngrok.

## Шаг 6. Приложение внутри Telegram (ngrok)

Telegram открывает приложения только по адресам, начинающимся с `https://`.
У вас на компьютере адрес `http://localhost` — Telegram его не видит.
Программа **ngrok** делает временный https-адрес, ведущий на ваш компьютер.

### 6.1. Установите ngrok (один раз)

1. Зарегистрируйтесь на **https://ngrok.com** (бесплатно, через Google).
2. Скачайте ngrok для своей системы и распакуйте.
3. В личном кабинете откройте раздел **Your Authtoken**, скопируйте токен.
4. Откройте **новое окно терминала** (первое с `dev.mjs` не трогаем!) и выполните:
   ```
   ngrok config add-authtoken СЮДА_ВАШ_ТОКЕН
   ```

### 6.2. Запустите туннель

В этом же новом окне:

```
ngrok http 5173
```

Окно заполнится текстом, найдите строку **Forwarding**:

```
Forwarding   https://abcd-12-34-56-78.ngrok-free.app -> http://localhost:5173
```

Больше здесь ничего делать не нужно — **это окно тоже не закрывайте**.

### 6.3. Адрес подставится сам

Вернитесь в **первое окно** (где работает `node dev.mjs`). Через несколько секунд там появится:

```
Найден адрес ngrok: https://abcd-12-34-56-78.ngrok-free.app
  Записал его в backend/.env и перезапускаю бота...
  Осталось один раз указать этот адрес в BotFather
```

### 6.4. Скажите Telegram про этот адрес

1. Откройте в Telegram **@BotFather**.
2. Отправьте `/mybots` и выберите своего бота.
3. **Bot Settings** → **Menu Button** → **Configure menu button**.
4. Вставьте адрес из пункта 6.3 и отправьте.
5. BotFather спросит название кнопки — напишите:
   ```
   Финансы
   ```

Готово. Откройте чат с ботом: слева от поля ввода появится кнопка **Финансы** —
нажмите её, откроется приложение с графиками, целями и историей.

> ⚠️ Бесплатный ngrok выдаёт **новый адрес при каждом запуске**.
> Если выключите и снова включите ngrok — адрес в `.env` обновится сам,
> но в BotFather (пункт 6.4) его придётся вставить заново.

## Шаг 7. Админ-панель

Откройте в браузере: **http://localhost:5174**

Пароль: тот, который вы задали в Шаге 3 (по умолчанию `finbot-admin`).
Забыли — посмотрите строку `ADMIN_TOKEN` в файле `finbot/backend/.env`.

Что там есть:
- **Обзор** — сколько пользователей, операций, график за 6 месяцев;
- **Операции** — таблица всех записей с фильтрами, можно удалять;
- **Категории** — добавить/изменить/удалить категорию, задать ключевые слова;
- **Пользователи** — язык, напоминания, детали по каждому; рассылка сообщений.

## Шаг 8. Как выключить и как включить снова

**Выключить:** в окне с `dev.mjs` нажмите `Ctrl + C`. То же самое в окне ngrok.

**Включить снова:**
1. Откройте терминал в папке `finbot` (Шаг 2).
2. Выполните `node dev.mjs`.
3. Если нужно приложение в Telegram — во втором окне `ngrok http 5173`
   и обновите адрес в BotFather.

Шаг 3 (настройку) повторять не нужно — она сделана один раз навсегда.

---

## Шаг 9. Смените ключи (важно!)

Токен бота и пароль базы были отправлены в переписку, поэтому их стоит поменять.

1. **Токен бота:** @BotFather → `/mybots` → ваш бот → **API Token** → **Revoke current token**.
   BotFather выдаст новый токен.
2. **Пароль базы:** Neon → ваш проект → **Dashboard** → **Reset password**.
   Скопируйте новую строку подключения.
3. Откройте терминал в папке `finbot` и выполните:
   ```
   node setup.mjs
   ```
   Скрипт спросит новую строку Neon и новый токен — просто вставьте их.

## Если что-то пошло не так

| Что видите | Что делать |
|---|---|
| `node : имя "node" не распознано` | Node.js не установлен или терминал не перезапущен — Шаг 0 |
| `npm.ps1 ... выполнение сценариев отключено` (Windows) | Выполните в PowerShell: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`, нажмите `Y`, затем повторите команду |
| `Не удалось подключиться к базе` | Проверьте интернет; зайдите на neon.tech и убедитесь, что проект не «спит» |
| `Telegram отклонил токен` | Токен скопирован не полностью или уже отозван — возьмите новый у BotFather |
| `Файл backend/.env не найден` | Вы пропустили Шаг 3 — выполните команду настройки |
| Бот молчит | Посмотрите окно `dev.mjs`: там должно быть `🤖 Бот @… запущен` |
| `409 Conflict` в окне бота | Бот запущен дважды — закройте лишнее окно терминала |
| Кнопка приложения открывает просто ссылку | Не настроен ngrok — Шаг 6 |
| `EADDRINUSE: port 4000` | Порт занят старым запуском — закройте все окна терминала и запустите `node dev.mjs` заново |
| Приложение в Telegram белое/пустое | Проверьте, что окно `dev.mjs` работает и ngrok указывает на порт `5173` |
