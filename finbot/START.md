# 🚀 Пошаговый запуск — для тех, кто не программист

> 📘 Полная инструкция от А до Я — [ИНСТРУКЦИЯ.md](./ИНСТРУКЦИЯ.md)
>
> **Хотите, чтобы бот работал круглосуточно и без вашего компьютера?**
> Это основной сценарий — он описан в файле **[DEPLOY.md](./DEPLOY.md)** (15 минут, бесплатно).
> Инструкция ниже нужна, только если хотите запускать проект у себя на компьютере.

Терминал не нужен: всё запускается двойным щелчком по файлу.
Делайте строго по шагам сверху вниз. Всего около 20 минут.

---

## Шаг 1. Установите Node.js (один раз)

Node.js — программа, которая умеет запускать наш проект.

1. Откройте **https://nodejs.org**
2. Нажмите большую зелёную кнопку с надписью **LTS**.
3. Запустите скачанный файл и нажимайте **Далее → Далее → Установить**, ничего не меняя.
4. **Перезагрузите компьютер.** Без этого система не увидит новую программу.

---

## Шаг 2. Скачайте проект

1. Откройте ссылку:
   **https://github.com/AdamKAI97/portfolio/tree/claude/speech-therapy-practice-platform-gnqgnc**
2. Зелёная кнопка **Code** → **Download ZIP**.
3. Скачается файл `portfolio-claude-speech-therapy-practice-platform-gnqgnc.zip`.
4. **Распакуйте его** (Windows: правой кнопкой → «Извлечь всё» → «Извлечь»).
   Просто открыть архив двойным щелчком **недостаточно** — нужно именно извлечь.
5. Зайдите в распакованную папку → внутри откройте папку **`finbot`**.

Вы должны увидеть внутри такие файлы и папки:

```
admin
backend
miniapp
1-НАСТРОЙКА-Windows.bat     (или 1-НАСТРОЙКА-Mac.command)
2-ЗАПУСК-Windows.bat        (или 2-ЗАПУСК-Mac.command)
3-ОБНОВИТЬ-Windows.bat      (или 3-ОБНОВИТЬ-Mac.command)
README.md
START.md
```

---

## Шаг 3. Настройка — двойной щелчок

**Windows:** двойной щелчок по файлу **`1-НАСТРОЙКА-Windows.bat`**

> Если Windows покажет синее окно «Система Windows защитила ваш компьютер» —
> нажмите **«Подробнее»** → **«Выполнить в любом случае»**. Это обычное предупреждение
> для файлов, скачанных из интернета.

**macOS:** правой кнопкой по файлу **`1-НАСТРОЙКА-Mac.command`** → **Открыть** → в окне
предупреждения ещё раз **Открыть**. (Первый раз именно правой кнопкой, не двойным щелчком.)

Откроется чёрное окно и задаст три вопроса — отвечайте по очереди:

1. **`Строка подключения Neon (DATABASE_URL):`**
   Вставьте строку вида `postgresql://neondb_owner:...` → Enter
2. **`Токен бота из BotFather (BOT_TOKEN):`**
   Вставьте токен вида `1234567890:AAE...` → Enter
3. **`Пароль для админ-панели [finbot-admin]:`**
   Придумайте пароль или просто нажмите Enter. **Запомните его** — понадобится в шаге 7.

> Как вставить текст в чёрное окно: правая кнопка мыши (в Windows) или `Cmd+V` (на Mac).

Дальше окно будет работать **3–5 минут** и много писать — это нормально.

**Что должно появиться в конце:**

```
  OK Таблицы созданы
✅ Готово: 10 категорий расходов, 5 категорий доходов.
  OK Бот найден: @ваш_бот (Мои финансы)

Настройка завершена.
```

**Запишите имя бота** (`@ваш_бот`) — понадобится в шаге 5.
Закройте окно.

Этот шаг делается **один раз**. Повторно он нужен, только если поменяете токен или пароль базы.

---

## Шаг 4. Запуск — двойной щелчок

**Windows:** двойной щелчок по **`2-ЗАПУСК-Windows.bat`**
**macOS:** двойной щелчок по **`2-ЗАПУСК-Mac.command`**

**Что должно появиться:**

```
Запускаю проект...

  бот и API   -> http://localhost:4000
  приложение  -> http://localhost:5173
  админка     -> http://localhost:5174

бот+api    | 🤖 Бот @ваш_бот запущен
```

⚠️ **Это окно закрывать нельзя.** Пока оно открыто — бот работает.
Закроете окно — бот выключится.

## Шаг 5. Проверьте бота в Telegram

1. В поиске Telegram наберите имя вашего бота (`@ваш_бот` из шага 3).
2. Нажмите **Start**.
3. Выберите язык: 🇷🇺 Русский или 🇺🇿 O'zbekcha.
4. Напишите боту обычное сообщение:
   ```
   45000 такси
   ```
   Бот ответит «✅ Записал» и сам определит категорию «Транспорт».
5. Попробуйте ещё:
   - `+3000000 зарплата` — это доход
   - `12k кофе` — расход 12 000
   - кнопка **📊 Отчёт** — сводка за месяц
   - кнопка **💡 Совет** — персональные советы по экономии

### Приложение можно посмотреть прямо в браузере

Откройте **http://localhost:5173** — это то же приложение, что будет внутри Telegram.
Удобно, чтобы посмотреть дизайн сразу, не дожидаясь публичного адреса.

## Шаг 6. Приложение внутри Telegram — включается само

Telegram открывает мини-приложения только по адресу с `https`, а на вашем компьютере
адрес `http://localhost`. Раньше для этого нужна была отдельная программа и настройка
в BotFather — **теперь проект делает это сам**.

Когда вы запускаете `2-ЗАПУСК`, в чёрном окне через несколько секунд появляется:

```
Публичный адрес приложения: https://что-то.trycloudflare.com
  Записал его в настройки и перезапускаю бота.
  Кнопку приложения в Telegram бот поставит сам — ничего делать не нужно.
```

После этого откройте чат с ботом: слева от поля ввода появится кнопка **Финансы**,
а в меню бота — кнопка **📱 Приложение**. Нажмите — откроется приложение
с графиками, целями и историей.

Если кнопки нет:
1. Закройте и снова откройте чат с ботом (Telegram кеширует кнопку меню).
2. Проверьте, что в чёрном окне есть строка «Публичный адрес приложения».
3. Если вместо неё написано «не удалось создать https-адрес» — проверьте интернет
   и запустите `2-ЗАПУСК` заново.

> Адрес меняется при каждом запуске — это нормально, бот обновляет кнопку сам.

## Шаг 7. Админ-панель

Откройте в браузере: **http://localhost:5174**

Пароль — тот, что вы задали в шаге 3 (по умолчанию `finbot-admin`).
Забыли — откройте файл `finbot/backend/.env` Блокнотом и посмотрите строку `ADMIN_TOKEN`.

Что там есть:
- **Обзор** — пользователи, операции, график за 6 месяцев;
- **Операции** — таблица всех записей с фильтрами, можно удалять;
- **Категории** — добавить, изменить, удалить, задать ключевые слова;
- **Пользователи** — язык, напоминания, детали, рассылка сообщений.

---

## Шаг 8. Как выключить и включить снова

**Выключить:** просто закройте окно из шага 4 — вместе с ним закроются бот, приложение и адрес.

**Включить снова:** двойной щелчок по **`2-ЗАПУСК-Windows.bat`** (или `2-ЗАПУСК-Mac.command`).
Настройку из шага 3 повторять не нужно.

---

## Шаг 9. Как обновлять проект

Когда появится новая версия, не нужно ничего скачивать вручную:
двойной щелчок по **`3-ОБНОВИТЬ-Windows.bat`** (на Mac — `3-ОБНОВИТЬ-Mac.command`).

Скрипт сам скачает свежие файлы и заменит старые. **Ваши ключи и настройки сохранятся**,
данные в базе тоже. После обновления запустите `2-ЗАПУСК`.

---

## Шаг 10. Смените ключи (важно)

Токен бота и пароль базы были отправлены в переписку, поэтому их стоит поменять.

1. **Токен бота:** @BotFather → `/mybots` → ваш бот → **API Token** → **Revoke current token**.
2. **Пароль базы:** Neon → ваш проект → **Dashboard** → **Reset password**.
3. Снова запустите **`1-НАСТРОЙКА-Windows.bat`** и вставьте новые значения.

## Если что-то пошло не так

| Что видите | Что делать |
|---|---|
| Окно моргнуло и закрылось | Не распакован ZIP — вернитесь к шагу 2, пункт 4 |
| `Node.js не найден` | Не установлен Node.js или не перезагружен компьютер — шаг 1 |
| «Система Windows защитила ваш компьютер» | «Подробнее» → «Выполнить в любом случае» |
| На Mac: «не удаётся открыть, неизвестный разработчик» | Правой кнопкой по файлу → **Открыть** → **Открыть** |
| `npm.ps1 ... выполнение сценариев отключено` | Запускайте через `.bat`-файл, а не через PowerShell |
| Кнопки «Финансы» нет в чате | Закройте и заново откройте чат с ботом |
| `Не удалось подключиться к базе` | Проверьте интернет; зайдите на neon.tech и убедитесь, что проект не «спит» |
| `Telegram отклонил токен` | Токен скопирован не полностью или отозван — возьмите новый у BotFather |
| `Сначала запустите файл 1-НАСТРОЙКА` | Пропущен шаг 3 |
| Бот молчит | В окне шага 4 должно быть `🤖 Бот @… запущен` |
| `409 Conflict` | Бот запущен дважды — закройте лишнее окно |
| `EADDRINUSE: port 4000` | Остался старый запуск — закройте все чёрные окна и запустите файл заново |
| Кнопка приложения открывает просто ссылку | Публичный адрес ещё не создан — см. шаг 6 |
