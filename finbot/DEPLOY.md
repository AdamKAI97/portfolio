# ☁️ Как включить бота навсегда (без вашего компьютера)

После этой настройки бот работает круглосуточно: компьютер можно выключить,
интернет дома отключить — бот всё равно отвечает и присылает напоминания.

Всё бесплатно и без банковской карты. Нужно около 15 минут.

---

## Что где будет жить

| Часть | Где | Стоимость |
|---|---|---|
| База данных | Neon (уже есть) | бесплатно |
| Бот, приложение, админка | Vercel | бесплатно |

---

## Шаг 1. Зарегистрируйтесь на Vercel

1. Откройте **https://vercel.com**
2. Нажмите **Sign Up** → выберите **Continue with GitHub**
3. Разрешите доступ (кнопка **Authorize Vercel**)
4. Если спросят про план — выберите **Hobby** (бесплатный) и своё имя

Карта не нужна.

---

## Шаг 2. Подключите проект

1. На главной Vercel нажмите **Add New…** → **Project**
2. В списке репозиториев найдите **portfolio** → **Import**
   - Если репозитория нет в списке: **Adjust GitHub App Permissions** → разрешите доступ к нему
3. Откроется страница настройки. Здесь важны три вещи:

**3.1. Root Directory** — нажмите **Edit** рядом с этим полем и выберите папку **`finbot`**.
Это обязательно, иначе Vercel не найдёт проект.

**3.2. Framework Preset** — оставьте **Other**.

**3.3. Environment Variables** — раскройте этот раздел и добавьте три переменные.
Для каждой: вписываете имя в поле **Key**, значение в поле **Value**, нажимаете **Add**.

| Key | Value |
|---|---|
| `DATABASE_URL` | строка подключения из Neon (`postgresql://neondb_owner:...`) |
| `BOT_TOKEN` | токен бота из BotFather |
| `ADMIN_TOKEN` | пароль для админ-панели — придумайте любой |

4. Нажмите большую кнопку **Deploy** и подождите 2–4 минуты.

Когда появится надпись **Congratulations** — сборка прошла успешно.

---

## Шаг 3. Укажите рабочую ветку

Код лежит не в главной ветке, поэтому Vercel нужно об этом сказать. Это делается один раз.

1. В проекте откройте **Settings** (вверху) → **Git** (слева)
2. Найдите поле **Production Branch**
3. Впишите:
   ```
   claude/speech-therapy-practice-platform-gnqgnc
   ```
4. Нажмите **Save**
5. Перейдите на вкладку **Deployments** → у верхней строки нажмите **⋯** → **Redeploy** → **Redeploy**

Подождите ещё пару минут.

---

## Шаг 4. Узнайте адрес сайта

Откройте вкладку **Project** (или **Overview**) — вверху будет адрес вида:

```
https://portfolio-xxxx.vercel.app
```

Это адрес вашего приложения. Откройте его в браузере — должно открыться финансовое приложение.

---

## Шаг 5. Подключите бота к облаку

Это делается один раз, одной ссылкой. Соберите адрес так:

```
https://ВАШ-АДРЕС.vercel.app/api/setup?token=ВАШ_ADMIN_TOKEN
```

Пример: если адрес `https://portfolio-abc.vercel.app`, а `ADMIN_TOKEN` вы задали `moy-parol`, то ссылка будет:

```
https://portfolio-abc.vercel.app/api/setup?token=moy-parol
```

Откройте её в браузере. Должна появиться страница **«✅ Бот подключён»** с именем вашего бота.

Если видите «Неверный пароль» — проверьте, что `ADMIN_TOKEN` в ссылке совпадает с тем,
что вы вписали в Vercel на шаге 2.

---

## Шаг 6. Проверьте

1. Откройте своего бота в Telegram, нажмите **Start**
2. Выберите язык
3. Напишите ему: `45000 такси` — он ответит «✅ Записал»
4. Слева от поля ввода появится кнопка **Финансы** — это приложение

**Выключите компьютер и напишите боту ещё раз.** Он ответит — значит всё работает.

Админ-панель: `https://ВАШ-АДРЕС.vercel.app/admin`, пароль — ваш `ADMIN_TOKEN`.

---

## Про ежедневные напоминания

Напоминание, недельный и месячный отчёты приходят автоматически.
На бесплатном тарифе Vercel проверка запускается **раз в сутки в 21:00 по Ташкенту**.

Хотите другое время — откройте файл `finbot/vercel.json` и поменяйте строку:

```json
"schedule": "0 16 * * *"
```

Здесь `16` — это час по Гринвичу. Ташкент = Гринвич + 5, то есть:
- `0 16 * * *` → 21:00 в Ташкенте
- `0 14 * * *` → 19:00 в Ташкенте
- `0 17 * * *` → 22:00 в Ташкенте

После изменения файла Vercel пересоберёт проект сам.

Если нужна точность до минуты и напоминания несколько раз в день, зарегистрируйтесь
на бесплатном **https://cron-job.org** и добавьте задание, которое раз в 15 минут
открывает адрес:

```
https://ВАШ-АДРЕС.vercel.app/api/cron?token=ВАШ_ADMIN_TOKEN
```

## Как обновлять бота дальше

Когда в проекте появляются изменения, Vercel подхватывает их сам —
через минуту после обновления кода на GitHub. Ничего нажимать не нужно.

---

## Если что-то пошло не так

| Что видите | Что делать |
|---|---|
| Сборка упала (красный **Error**) | Откройте **Deployments** → нажмите на неудачную сборку → **Build Logs**, пришлите мне последние строки |
| `404: NOT_FOUND` при открытии сайта | Не указан **Root Directory = finbot** (шаг 2.1) или не выбрана ветка (шаг 3) |
| Страница `/api/setup` пишет «Неверный пароль» | `token` в ссылке не совпадает с `ADMIN_TOKEN` в переменных Vercel |
| Бот не отвечает | Откройте `/api/setup?token=…` ещё раз; проверьте, что `BOT_TOKEN` вписан без пробелов |
| Ошибка про базу данных | Проверьте `DATABASE_URL`; зайдите на neon.tech и убедитесь, что проект активен |
| Приложение открывается, но пустое | Подождите минуту — база «просыпается» после простоя |

---

## Локальный запуск никуда не делся

Если захотите что-то проверить у себя на компьютере — всё работает как раньше:
`1-НАСТРОЙКА` и `2-ЗАПУСК`. Облако и локальный режим друг другу не мешают,
база у них общая.
